# Игроки NBA: когда пора на пенсию?

> Single-file HTML scrollytelling о возрастных кривых игроков NBA.

Вертикальный нарратив со sticky-графикой: в каком возрасте игрок выходит на пик и
когда начинается спад, и как это зависит от амплуа, навыка и эпохи. Один
self-contained `index.html` — открывается двойным кликом, без сборки и сервера.

**Вывод за 10 секунд:** пик ≈ 26–28 лет, дальше спад; большие сваливаются раньше
защитников; современные карьеры длиннее.

## Быстрый старт

```bash
task install     # зависимости пайплайна (Python)
task build       # тесты → данные → встраивание JSON в index.html → валидация
task open        # открыть готовый дашборд в браузере
```

> Нужны Python 3, Node.js и [Task](https://taskfile.dev). Подробнее —
> [docs/getting-started.md](docs/getting-started.md).

## Ключевые особенности

- **Скроллителлинг, не BI-дашборд** — одна мысль на сцену, sticky-графика, 7 сцен (US-1…US-7).
- **Честность данных** — кривые старения строятся дельта-методом на скоростных
  метриках (per-36) с контролем survivorship bias.
- **Самодостаточный файл** — данные предвычислены офлайн и встроены инлайн
  (слим-JSON < 300 КБ); в браузере нет рантайм-загрузки.
- **Ремесло дата-виз** — минимум не-данных, прямые подписи, ≤ 2 шрифтов,
  семантический theme-aware цвет, светлая/тёмная тема.
- **Доступность** — уважает `prefers-reduced-motion`, интерфейс на русском.

## Как это устроено

Двухфазный слоевой пайплайн (детали — [.ai-factory/ARCHITECTURE.md](.ai-factory/ARCHITECTURE.md)):

```
Kaggle-датасет → Python-пайплайн (дельта-метод, per-36, survival) → слим-JSON → index.html
```

Фаза 1 (данные, TDD) не пускает Фазу 2 (HTML), пока тесты пайплайна не зелёные.
