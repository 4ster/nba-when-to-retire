# Игроки NBA: когда пора на пенсию?

> Single-file HTML scrollytelling о возрастных кривых игроков NBA.

Вертикальный нарратив со sticky-графикой: в каком возрасте игрок выходит на пик и
когда начинается спад, и как это зависит от амплуа, навыка и эпохи. Один
self-contained `index.html` — открывается двойным кликом, без сборки и сервера.

**Вывод за 10 секунд:** пик ≈ 26–28 лет, дальше спад; большие сваливаются раньше
защитников; современные карьеры длиннее.

## Быстрый старт

```bash
task open        # открыть готовый дашборд (данные уже встроены в index.html)
```

Пересборка из исходных данных:

```bash
task install     # зависимости пайплайна (Python) и инструментов (Node: jsdom, d3)
task download    # скачать датасет sumitrodatta/nba-aba-baa-stats (нужны kaggle CLI + токен)
task build       # тесты → агрегация → встраивание JSON в index.html → валидация
```

> `index.html` самодостаточен и уже содержит данные по сезон 2025–26
> (охват сезонов NBA 1951–52 … 2025–26). Диапазон и метка данных выводятся из датасета.
> Для пересборки нужны Python 3, Node.js, [Task](https://taskfile.dev) и Kaggle-доступ
> (см. [docs/getting-started.md](docs/getting-started.md)).

## Ключевые особенности

- **Скроллителлинг, не BI-дашборд** — одна мысль на сцену, sticky-графика, 7 сцен (US-1…US-7).
- **Честность данных** — кривые старения строятся дельта-методом на скоростных
  метриках (per-36) с контролем survivorship bias.
- **Самодостаточный файл** — данные предвычислены офлайн и встроены инлайн
  (слим-JSON < 300 КБ); в браузере нет рантайм-загрузки.
- **Ремесло дата-виз** — минимум не-данных, прямые подписи, ≤ 2 шрифтов,
  семантический theme-aware цвет, светлая/тёмная тема.
- **Прозрачность метода** — кнопка «?» открывает модалку с описанием датасета и
  методики (дельта-метод, per-36, survivorship, цензурирование, оговорки).
- **Доступность** — уважает `prefers-reduced-motion`, доступная модалка (focus-trap,
  Esc, `aria-modal`), интерфейс на русском.

## Как это устроено

Двухфазный слоевой пайплайн (детали — [.ai-factory/ARCHITECTURE.md](.ai-factory/ARCHITECTURE.md)):

```
Kaggle-датасет → Python-пайплайн (дельта-метод, per-36, survival) → слим-JSON → index.html
```

Фаза 1 (данные, TDD) не пускает Фазу 2 (HTML), пока тесты пайплайна не зелёные.

## Статус

Готово на реальных данных (`sumitrodatta/nba-aba-baa-stats`, сезоны NBA 1952–2026,
по сезон 2025–26, встроены в `index.html`): офлайн-пайплайн (Python, 76 тестов —
дельта-метод, per-36, survival, skill_decline, notable, схема + бюджет) и `index.html`
(d3-скроллителлинг: 7 сцен US-1…US-7, светлая/тёмная темы, песочница, модалка о методике).
Результат честен: пик ценности ≈ 25–26 лет, медиана ухода поздняя, долгожители
(LeBron James, Vince Carter) против рано угасших (Andrew Bynum, Darius Bazley).
Браузерная проверка подзаголовка-диапазона и модалки — `task verify` (jsdom, зелёная).
