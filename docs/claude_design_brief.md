# Задание для Claude Design: редизайн-ревью дашборда «Карьеры игроков НБА»

## Контекст
Приложен self-contained HTML-дашборд для конкурса BI-аналитики (50 баллов: смысл 9 /
структура 7 / визуализация 8 / интерактив 9 / дизайн 7 / оригинальность 10).
Аудитория — аналитик/менеджер фронт-офиса НБА. Вопрос дашборда: «игроку N лет —
сколько ценности впереди и когда контракт становится риском».

Структура: шапка с фильтрами → 5 KPI + карточка «Что если» → ряд «Модель старения»
(кривая ценности с зоной контрактного риска, запас ценности по амплуа, расцвет
навыков) → ряд «Отдельные карьеры» (1305 пиков карьер, возраст ухода, таблица).
Две темы (тёмная по умолчанию и светлая), один экран без прокрутки на 1920×1080.

## Что НЕ трогать (жёсткие ограничения)
- Состав и смысл визуалов, все числа, подписи данных, формулы — не менять.
- Семантику цветов: оранжевый = ценность (BPM), синий = защитники,
  жёлтый = форварды, фиолетовый = большие, зелёный = «мастерство»/позитив,
  красный = риск. Оттенки менять можно, назначение — нет.
- Принципы: без осей и линий сетки, прямые подписи на данных, ≤2 гарнитур
  (сейчас Oswald + Segoe UI), один экран без вертикальной прокрутки.
- Никаких внешних ресурсов (CDN, веб-шрифты по ссылке) — файл работает офлайн.

## Что хочу улучшить (зоны работы)
1. **Первое впечатление.** Дашборд аккуратный, но сдержанный. Хочу «вау» для жюри
   за первые 5 секунд без потери строгости: предложи 2–3 направления
   (например, выразительнее шапка, глубина поверхностей, акцентная графика фона).
2. **Палитра.** Проверь оттенки на обеих темах: жёлтый (форварды) на светлой теме
   выглядит грязновато; оранжевый акцент и красная зона риска местами спорят.
   Предложи уточнённые хексы при том же назначении цветов.
3. **Иерархия KPI-ряда.** 6 карточек (5 показателей + «Что если») читаются ровно;
   хочу, чтобы «Пик ценности 25 лет» и «Спад после 30» считывались первыми.
4. **Типографика и плотность.** Проверь размеры/веса/межстрочные, отступы карточек,
   радиусы и тени — где дышит плохо, где можно строже.
5. **Карточка «Запас ценности»** — три горизонтальных бара в высокой карточке,
   многовато воздуха. Предложи лучшую компоновку без смены типа графика.
6. **Ревью доступности**: контраст текстов и меток на обеих темах (WCAG AA).

## Формат результата
- Сначала 2–3 эскиза-направления на канвасе, обсуждаем, выбираю одно.
- Финал: список конкретных решений — хексы палитры для обеих тем, размеры
  шрифтов, отступы, радиусы, тени + скриншоты. Полный HTML-экспорт не нужен:
  изменения будут вживляться в исходники проекта вручную.
