# Арт-дирекция (редизайн v3)

Презентационный слой `index.html`: спокойный аналитический разбор возрастных кривых — одна
сцена, один факт, один подходящий тип графика. Этот документ описывает, **как устроена
визуальная часть** — вендоринг, токены, движок и семь сцен. Источники-истины:
[DESIGN.md](../DESIGN.md) (enforceable-токены и правила), [BRIEF.md](../BRIEF.md) (креатив),
[RULES.md](../RULES.md) (аксиомы). Контракт данных **не меняется** — см. [Data Pipeline](data-pipeline.md).

## Кратко

- **Строгий офлайн.** Ни одного внешнего `<script src>`/`<link href>`: d3, scrollama и шрифт
  Oswald встроены в `index.html`. Файл открывается двойным кликом без сети.
- **Ровно 2 семейства.** Oswald (display) встроен base64-woff2; системный гротеск — для текста
  и данных. Третьего, включая моноширинное, нет; числа — `tabular-nums`.
- **Тёмная тема — стартовая** (`<html data-theme="dark">`); светлая — полнофункциональная.
- **Один sticky-канвас**, без осей: смена сцен — морф существующих элементов; в ключевых точках —
  прямые метки данных с анти-коллизией; каждая кодировка подписана.
- **Семь типов графиков** под инсайты (не семь кривых): линия, slope, lollipop, наложение эпох,
  dumbbell, гистограмма, интерактив.
- **Аналитический голос.** Заголовки — утверждения-факты; без драматизации и пафоса.
- **Адаптив** mobile-first (нет overflow на 360px), навигация по сценам, фильтры US-7 сверху.
- **Числа в заголовках сверяются** с агрегатами слим-JSON через `console.assert`.

## Офлайн-вендоринг ассетов

Большие ассеты встраиваются build-утилитой `tools/inline_assets.mjs` (идемпотентно, по образцу
`pipeline/embed.py`): она заменяет внутренность узлов-плейсхолдеров в `index.html`.

| Ассет | Источник | Узел в `index.html` | Бюджет |
|-------|----------|---------------------|--------|
| d3 v7.9.0 | `node_modules/d3/dist/d3.min.js` (npm) | `<script id="vendor-d3">` | вендор ≤ 350 КБ |
| scrollama v3.2.0 | `tools/vendor/scrollama.min.js` | `<script id="vendor-scrollama">` | (в т.ч. d3) |
| Oswald v57 | `tools/vendor/oswald-{latin,cyrillic}.woff2` | `<style id="font-faces">` | шрифты ≤ 90 КБ |

Шрифт — сабсет latin+cyrillic; Oswald вариативный, поэтому один woff2 на оба веса (`font-weight: 500 600`).
Запуск вручную: `node tools/inline_assets.mjs index.html` (или `task inline`); в `task build`
вендоринг идёт автоматически перед встраиванием слим-JSON.

## Токены DESIGN §1

Все цвета, размеры шрифта и тайминги — только через CSS-переменные; JS читает их через
`getComputedStyle` (hex-литералов в JS-отрисовке нет).

| Группа | Токены | Заметки |
|--------|--------|---------|
| Цвет | `--bg --surface --fg --muted --hair --accent --label`, семантика `--c-guard/-wing/-big`, `--c-era-pre/-mid/-modern`, `--ghost --band` | тёмная (`:root`) + светлая (`[data-theme=light]`) |
| Шрифты | `--font-display` (Oswald), `--font-text` (системный) | ровно 2 семейства |
| Шкала | `--fs-giant/-h1/-h2/-lede/-body/-label` | `clamp()` для адаптива |
| Отступы | `--s-1 … --s-16` (база 4px) | геометрия |
| Тайминги | `--t-fast/-step/-scene/-theme`, `--ease` | при `prefers-reduced-motion` морфы → 0мс |

`--accent` (оранжевый мяча) появляется не более чем в одном смысловом элементе на сцену
(пик US-1, полоса «разрыв эпох» US-4, медиана US-6, выбор US-7). Декора нет: фонового числа,
неподписанных полос и градиентов в v3 убраны.

## Движок (метки вместо осей)

Единственный `<svg id="chart">` создаётся один раз (`initEngine`); внутри — персистентные
слои-`<g>` (`band, lines, marks, labels`). Смена сцены — `update`/морф существующих элементов
через d3 data-join с переходами, **а не** `innerHTML`-перерисовка. Осей/сетки/рамок **нет**:
в ключевых точках стоят прямые метки данных, разведённые анти-коллизией (`declutter`); каждая
визуальная кодировка подписана. Длительности — из токенов `--t-*`, easing — d3-аналог `--ease`
(`easeCubicOut`).

## Семь сцен (свой тип графика на инсайт)

У каждой сцены — `data-signature` и собственный тип графика; ни один не повторяется. Заголовки —
утверждения-факты из `BRIEF.md §6`, числа из данных (сверяются `console.assert`).

| Сцена | `data-signature` | Тип графика | Заголовок |
|-------|------------------|-------------|-----------|
| US-1 | `us1-mountain` | линия + подписанный доверительный коридор; метка пика | «Пик ценности — 25 лет» |
| US-2 | `us2-split` | slope амплуа (пик → 34), подпись развилки | «После 27 траектории амплуа расходятся» |
| US-3 | `us3-board` | ранжированный lollipop возраста спада + пометка survivorship | «Атлетизм снижается раньше бросковых навыков» |
| US-4 | `us4-film` | наложение эпох (цвет + фактура) + подписанная полоса «разрыв эпох» | «Современные карьеры длятся дольше» |
| US-5 | `us5-spotlight` | dumbbell диапазонов карьер `notable` | «Длина карьеры — от 3 до 23 сезонов» |
| US-6 | `us6-cliff` | гистограмма возраста ухода + флажок медианы | «Половина уходит из лиги к 28» |
| US-7 | `us7-clipboard` | интерактив: фильтры сверху, выбор vs подписанная средняя-призрак, сброс | «Соберите свою кривую» |

### Акцентный переход

Один заметный переход (остальные — стандартный `--t-scene`): при US-1 → US-2 средняя кривая
сменяется тремя slope-сегментами амплуа, расходящимися от общего пика — кодирует декомпозицию
средней. При `prefers-reduced-motion` морфы заменяются мгновенной сменой; все выводы читаются
без анимации.

## Сверка чисел (console.assert)

Функция `reconcile()` вычисляет ключевые числа из агрегатов и проставляет их в заголовки
(`#hl-peak`, `#hl-div`, `#hl-med`, `#hl-fade`, `#hl-long`), затем `console.assert` проверяет, что
текст заголовка совпадает с агрегатом и числа в допустимых диапазонах (пик в [18,42];
развилка/медиана конечны; длина карьер `min < max`).

## Сборка и гейт приёмки

```bash
task build     # тесты → данные → вендоринг (inline) → встраивание JSON → check_html
task verify    # jsdom: офлайн+dark, метки-без-осей, 7 типов графиков, навигация, фильтры сверху, голос, бюджеты, модалка/a11y
task ci        # build + verify
```

Гейт приёмки v3 проверяет: pytest (пайплайн без регресса), `check_html` (один JS-блок, синтаксис,
нет null-байтов), расширенный `tools/verify_dom.mjs` (нет осей и есть прямые метки; типы графиков
по сценам; навигация; фильтры US-7 сверху; нет kicker «СЦЕНА N»; аналитический голос без
запрещённой лексики; `console.assert` без провалов) и бюджеты — вендор ≤ 350 КБ, шрифты ≤ 90 КБ,
дизайн (шрифты + CSS) ≤ 150 КБ, слим-JSON < 300 КБ. Визуальная проверка обеих тем и ширин
360/768px — вручную (`task open`, переключатель «◐ Тема»).
