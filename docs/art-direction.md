# Арт-дирекция (редизайн v2)

Презентационный слой `index.html`: образ «арена после финальной сирены». Этот документ
описывает, **как устроена визуальная часть** — вендоринг, токены, морф-движок и семь сцен.
Источники-истины: [DESIGN.md](../DESIGN.md) (enforceable-токены и правила), [BRIEF.md](../BRIEF.md)
(креатив), [RULES.md](../RULES.md) (аксиомы). Контракт данных **не меняется** — см.
[Data Pipeline](data-pipeline.md).

## Кратко

- **Строгий офлайн.** Ни одного внешнего `<script src>`/`<link href>`: d3, scrollama и шрифт
  Oswald встроены в `index.html`. Файл открывается двойным кликом без сети.
- **Ровно 2 семейства.** Oswald (display) встроен base64-woff2; системный гротеск — для текста
  и данных. Третьего, включая моноширинное, нет; числа — `tabular-nums`.
- **Тёмная тема — стартовая** (`<html data-theme="dark">`); светлая — полнофункциональная.
- **Один sticky-канвас** морфит через все 7 сцен (не пересоздаётся), с двумя «вау»-переходами.
- **Числа в заголовках сверяются** с агрегатами слим-JSON через `console.assert`.

## Офлайн-вендоринг ассетов

Большие ассеты встраиваются build-утилитой `tools/inline_assets.mjs` (идемпотентно, по образцу
`pipeline/embed.py`): она заменяет внутренность узлов-плейсхолдеров в `index.html`.

| Ассет | Источник | Узел в `index.html` | Бюджет |
|-------|----------|---------------------|--------|
| d3 v7.9.0 | `node_modules/d3/dist/d3.min.js` (npm) | `<script id="vendor-d3">` | вендор ≤ 350 КБ |
| scrollama v3.2.0 | `tools/vendor/scrollama.min.js` | `<script id="vendor-scrollama">` | (в т.ч. d3) |
| Oswald v57 | `tools/vendor/oswald-{latin,cyrillic}.woff2` | `<style id="font-faces">` | шрифты ≤ 90 КБ |

Шрифт — сабсет latin+cyrillic; Oswald вариативный, поэтому один woff2 на оба веса (`font-weight: 500 600`).
Запуск вручную: `node tools/inline_assets.mjs index.html` (или `task inline`); в `task build`
вендоринг идёт автоматически перед встраиванием слим-JSON.

## Токены DESIGN §1

Все цвета, размеры шрифта и тайминги — только через CSS-переменные; JS читает их через
`getComputedStyle` (hex-литералов в JS-отрисовке нет).

| Группа | Токены | Заметки |
|--------|--------|---------|
| Цвет | `--bg --surface --fg --muted --hair --accent --label`, семантика `--c-guard/-wing/-big`, `--c-era-pre/-mid/-modern`, `--ghost --band --jersey` | тёмная (`:root`) + светлая (`[data-theme=light]`) |
| Шрифты | `--font-display` (Oswald), `--font-text` (системный) | ровно 2 семейства |
| Шкала | `--fs-giant/-h1/-h2/-kicker/-lede/-body/-label` | `clamp()` для адаптива |
| Отступы | `--s-1 … --s-16` (база 4px) | геометрия |
| Тайминги | `--t-fast/-step/-scene/-fall/-theme`, `--ease` | при `prefers-reduced-motion` морфы → 0мс |

`--accent` (оранжевый мяча) появляется не более чем в одном смысловом элементе на сцену
(пик US-1, заливка хвоста US-4, медиана US-6, выбор US-7).

## Морф-движок

Единственный `<svg id="chart">` создаётся один раз (`initEngine`); внутри — персистентные
слои-`<g>` (`band, grid, lines, multiples, bars, fall, axis, labels`) и фоновый джерси-номер.
Смена сцены — это `update`/морф существующих элементов через d3 data-join с переходами
(`enter`/`update`/`exit` + `transition`), **а не** `innerHTML`-перерисовка. Длительности берутся
из токенов `--t-*`, easing — d3-аналог `--ease` (`easeCubicOut`).

## Семь сцен

У каждой сцены — атрибут `data-signature` и собственный сигнатурный приём; ни один не
повторяется. Заголовки редакторские (≤ 7 слов, число или глагол), числа — из данных.

| Сцена | `data-signature` | Приём | Заголовок |
|-------|------------------|-------|-----------|
| US-1 | `us1-mountain` | линия-герой + коридор + градиент выцветания после пика + джерси-номер пика | «В N — потолок. Дальше вниз» |
| US-2 | `us2-split` | расщепление средней на 3 амплуа + вертикаль развилки | «Большие стареют первыми» |
| US-3 | `us3-board` | small multiples с номерами Oswald, порядок по возрасту пика | «Первым гаснет …, дольше держится …» |
| US-4 | `us4-film` | эпохи фактурой штриха (пунктир/толщина) + заливка зазора хвостов | «Современные доигрывают дольше» |
| US-5 | `us5-spotlight` | средняя-призрак + именные траектории (`notable`) | «Одни гаснут в N, другие — до M» |
| US-6 | `us6-cliff` | осыпание точек в гистограмму ухода + флажок медианы | «Лига просто перестаёт звонить» |
| US-7 | `us7-clipboard` | планшет: сегмент-контролы (амплуа/эпоха/метрика), базовая-призрак, сброс | «Соберите свою кривую» |

### Два «вау»-перехода

Ровно два расширенных перехода (остальные — стандартный `--t-scene`):

1. **Расщепление US-1 → US-2.** Три кривые амплуа «выезжают» из формы средней (`enter` стартует
   из геометрии средней, затем `d` интерполируется к собственным точкам).
2. **Осыпание US-5 → US-6.** Точки-карьеры падают сверху в бины гистограммы возраста ухода
   (`--t-fall`, staggered delay), кодируя переход от траекторий к распределению.

При `prefers-reduced-motion` морфы заменяются мгновенной сменой состояния — все выводы читаются
без анимации.

## Сверка чисел (console.assert)

Функция `reconcile()` вычисляет ключевые числа из агрегатов и проставляет их в заголовки
(`#hl-peak`, `#hl-div`, `#hl-med`, `#hl-fade`, `#hl-long`, `#hl-first`, `#hl-last`), затем
`console.assert` проверяет, что текст заголовка совпадает с агрегатом и числа в допустимых
диапазонах (пик в [18,42], развилка/медиана конечны). Джерси-номер US-1 равен возрасту пика.

## Сборка и гейт приёмки

```bash
task build     # тесты → данные → вендоринг (inline) → встраивание JSON → check_html
task verify    # jsdom: офлайн+dark, 7 сигнатур, морф сцен на одном канвасе, модалка/a11y, 0 ошибок
task ci        # build + verify
```

Гейт приёмки v2 проверяет: pytest (пайплайн без регресса), `check_html` (один JS-блок, синтаксис,
нет null-байтов), расширенный `tools/verify_dom.mjs` и бюджеты — вендор ≤ 350 КБ, шрифты ≤ 90 КБ,
дизайн (шрифты + CSS) ≤ 150 КБ, слим-JSON < 300 КБ. Визуальная проверка обеих тем — вручную
(`task open`, переключатель «◐ Тема»).
