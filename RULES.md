# RULES — «Игроки NBA: когда пора на пенсию?»

Проектные аксиомы. Принудительно проверяются `/aif-verify` и `/aif-review` как read-only гейт.
Это enforceable-экстракт; полный замысел — в `spec.md`.

## Архитектура и формат
- MUST: один self-contained HTML, открывается двойным кликом, без сборщика и сервера; данные встроены инлайн.
- MUST: агрегация данных — офлайн, build-time (Python/pandas); браузер потребляет только готовый слим-JSON (< 300 КБ).
- MUST NOT: рантайм-загрузка данных в браузере (никаких `fetch` к источникам/эндпоинтам в финальном файле). Обновление = пересборка офлайн-пайплайном.
- MUST: дата данных проставлена в UI («данные по сезон 20XX–XX»).

## Жанр и компоновка
- MUST: скроллителлинг — вертикальный нарратив, sticky-графика, одна мысль на сцену.
- MUST NOT: BI-сетка KPI-карточек или «один экран без прокрутки» (компоновка insba §3 НЕ применяется).

## Достоверность данных
- MUST: кривые старения строятся дельта-методом (год-к-году по одному игроку).
- MUST: скоростные метрики (per-36 / per-100), не суммарные.
- MUST: контроль survivorship bias.
- MUST NOT: внеигровые данные (зарплаты, реклама, мотивация).
- MUST: неопределённость и оговорки показаны — доверительный коридор и `n`, аннотации про дельта-метод, survivorship и эпохальный конфаунд.

## Процесс
- MUST: тесты раньше реализации (TDD). Логику агрегации (дельта-метод, per-36, survivorship, схема, бюджет размера) покрыть тестами до фронта.
- MUST NOT: начинать фронт, пока тесты пайплайна не зелёные.
- MUST: делать ровно то, что в плане; идеи вне скоупа — в отдельный список, не в активный план.

## Дата-виз (insba §5)
- MUST: убраны оси, сетка, рамки канваса, подписи делений; значения — на метках данных; при перегрузе — тултип, а не возврат осей.
- MUST: единицы — в заголовке графика (в легенде только для комбинированных осей); на метках данных единиц нет; ≤ 3–4 значащих цифры.
- MUST NOT: вертикальный или диагональный текст в графиках.

## Цвет и тема (insba §7, §3.5)
- MUST: цвет несёт смысл (семантика амплуа/эпохи), не декор.
- MUST: цвет меток theme-aware (тёмный на светлой теме, авто-контраст на тёмной); без обводок `paint-order:stroke`.
- MUST: при фильтрации палитра стабильна — `domain` берётся из полного набора, не из отфильтрованного.
- MUST: переключатель темы не ломает контраст и читаемость графиков ни в одной теме.
- MUST NOT: лишний декор — градиенты, глубокие тени, свечения, скевоморфизм, эмодзи вместо иконок.

## Типографика (insba §8)
- MUST: не более 2 шрифтов.

## Сборка и валидация (insba §21)
- MUST: один JS-блок (не дробить ради лимитов инструментов).
- MUST: `node --check` после каждой сборки; strip null-байтов.
- MUST: seed-данные как `<script id="seed-data" type="application/json">`, `JSON.parse` на `DOMContentLoaded` в `try/catch`.
- MUST: стартовый атрибут `data-theme` на `<html>`.
- MUST: CDN-ссылки с зафиксированными версиями, без `@latest`.

## Доступность
- MUST: уважать `prefers-reduced-motion` — отключать анимации.
- MUST: у иконных кнопок есть `title` и `aria-label`.

## Язык
- MUST: интерфейс на русском.
