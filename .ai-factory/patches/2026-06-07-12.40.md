# Робастность амплуа, синхронизация темы и чистый коридор aging

**Date:** 2026-06-07 12:40
**Files:** pipeline/transform/normalize.py, pipeline/transform/aging.py, index.html, pipeline/tests/test_normalize.py
**Severity:** high

## Problem

Три находки код-ревью:
1. **(high)** `position_group` бросал `ValueError` на любом коде амплуа вне
   `{PG,SG,SF,PF,C}`. Реальные датасеты NBA содержат составные/краткие коды
   (`G`, `F`, `G-F`, `PG-SG`, `F-C`) — первый же реальный `task build` упал бы,
   хотя тесты на «чистой» синтетике были зелёными.
2. **(low)** Переключатель темы перерисовывал только активную сцену (`#chart`),
   а песочница (`#sandbox-chart`) оставалась в цветах прошлой темы до следующего
   изменения фильтра — нарушение «тема не ломает контраст ни в одной теме».
3. **(low)** `aging_curve` считал коридор через `np.where`, где для `n<2`
   `se` = NaN; ветка не выбиралась, но вычислялась — лишняя NaN-арифметика.

## Root Cause

1. Маппинг амплуа был выведен из формата синтетических тестовых данных, а не из
   реального источника. Класс ошибки: **«тесты на синтетике скрывают допущения о
   форме реальных данных»** — счастливый путь (чистые коды) покрыт, граничные
   реальные коды — нет.
2. Логика обновления песочницы была заперта в замыкании `initSandbox.update` и
   недоступна обработчику темы; единый ре-рендер не был предусмотрен.
3. Защита от NaN делалась через `np.where` постфактум вместо устранения NaN в
   источнике (`se`).

## Solution

1. `position_group`: пробуем полный код, затем первый токен до `-`/`/`/пробела;
   расширенный маппing (`G→guard`, `F→wing`, `GF→wing`, `FC→big`); для
   нераспознанного — `log.warning` + fallback `wing`, без падения билда. Добавлены
   параметрические тесты на составные/краткие/неизвестные коды и `None`.
2. Введён модульный хук `sandboxRerender` (ставится в `initSandbox`), который
   обработчик темы вызывает вместе с `rerenderActiveScene()`.
3. `se = (sd/sqrt(n)).fillna(0.0)` → коридор сам схлопывается в `value` при `n<2`;
   `np.where`/`has_spread` убраны.

Проверено: 56 тестов pytest зелёные, ruff чист, `check_html` OK, jsdom-прогон
(смена темы → песочница перерисована; сборка с `G-F` без падения).

## Prevention

- **Граничные данные в тестах:** для парсеров/нормализаторов внешних данных всегда
  добавлять кейсы с «грязными»/составными/пустыми значениями, а не только канонические.
- **Не ронять весь билд** на одной нераспознанной записи — fallback + `log.warning`.
- **Единый ре-рендер для смены темы:** любой график, читающий CSS-токены, должен
  иметь хук перерисовки, дёргаемый из переключателя темы (проверять в jsdom кликом).
- **Устранять NaN в источнике**, а не маскировать `np.where`.
- **Запускать инициализацию в конце IIFE** (после всех `var`/функций) — ранее
  пойман класс hoisting-багов (init до присваивания `currentScene`/`MARGIN`).
