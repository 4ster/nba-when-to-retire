## Шаг 1 — утверждённые инсайты (вход для Шага 2)

Числа посчитаны из `data/aging.json`; в реализации закрепляются `console.assert`.

| Сцена | Заголовок (аналитич.) | Тип графика | Ключевые числа |
|---|---|---|---|
| US-1 | Пик ценности — 25 лет | линия + доверительный коридор | пик = 25 |
| US-2 | После 27 траектории амплуа расходятся | slope (пик → 34) по амплуа | развилка = 27; big падает ниже всех |
| US-3 | Атлетизм снижается раньше бросковых навыков | ранжированный lollipop | блок 20 · подбор 23 · перехват 24 · очки 35 |
| US-4 | Современные карьеры длятся дольше | наложение эпох + полоса «разрыв эпох» | выборка до 37 (1990+) vs 34 (≤1989) |
| US-5 | Длина карьеры — от 3 до 23 сезонов | dumbbell диапазонов карьер | min 3 (Bazley) · max 23 (LeBron) |
| US-6 | Половина уходит из лиги к 28 | гистограмма возраста ухода + медиана | медиана = 28; пик ухода 24–25 |
| US-7 | Соберите свою кривую | интерактивная линия + средняя-призрак | — |

### Поправки к докам (вскрыты данными)
1. **US-2 «Большие стареют первыми» — НЕ подтверждается** (пики амплуа 25/26/25 ≈ равны). Заменено на «расхождение после 27».
2. **US-3 поздние «пики» AST/FG3/TS (36–37) и REB/PTS на 40–42 (n=8/4/2)** — survivorship/малая выборка, не инсайт. Ранжируем по high-n спаду, поздние всплески оговариваем.
3. **US-6 survival 62% в 40 лет — n=8**, недостоверно. Распределение ограничиваем надёжными возрастами.
4. **US-4 высокий пик средней эпохи (7.5)** — эффект состава/метрики; в заголовок не выносим.

## Ключевые ограничения

- Данные/агрегаты/пайплайн неизменны; строгий офлайн; один self-contained HTML; ≤ 2 шрифта.
- Голос — сухо-аналитический: запрет морбид-лексики (угасание, умирание, гаснут, потолок, помойка, вспышка, элегия) и пафоса (величие, переизобретают); метафоры дизайна (хроника/плёнка/LED) не в UI-текст. Заголовок дашборда «Игроки NBA: когда пора на пенсию?» не менять.
- Нет осей/сетки → прямые метки данных в ключевых точках; нет неподписанных кодировок.
- Нет горизонтального overflow на 360px; адаптив 360–768; навигация по сценам; фильтры US-7 сверху.
- Бюджеты: вендор ≤ 350 КБ, шрифты ≤ 90 КБ, дизайн ≤ 150 КБ, слим-JSON < 300 КБ.
