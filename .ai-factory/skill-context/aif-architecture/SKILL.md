## Rules

### Per-dataset adapter, not a global column_map
**Source**: 2026-06-07-13.15.md
**Rule**: Integrating an external dataset into the §2 contract requires more than column
renaming — derived fields must be synthesized (e.g. `player_id` from name via `factorize`,
`active_next` from presence in the next season), and source quirks handled (traded-player
`TOT` dedup). Put this in a dedicated, unit-testable per-dataset adapter module
(`pipeline/datasets.py`, registered in `DATASET_LOADERS`, selected via `build --dataset`),
not in a generic `column_map`. Keep `fetch.load_raw` for already-conformant CSVs only.
