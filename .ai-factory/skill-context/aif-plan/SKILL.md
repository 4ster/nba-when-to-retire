### Plan dirty-data test tasks for any external-data parser
**Source**: 2026-06-07-12.40.md, 2026-06-07-13.15.md
**Rule**: When planning tasks that parse/normalize external datasets, the test task MUST
explicitly cover dirty-data edge cases — combined/abbreviated/empty codes, `NaN` and all-NA
series, duplicate records (e.g. traded-player rows), and partial metric coverage by year
(e.g. advanced stats missing before a certain season). Canonical synthetic data alone hides
the real bugs that surface on the actual dataset.
