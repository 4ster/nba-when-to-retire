**Source**: 2026-06-07-12.40.md, 2026-06-07-13.15.md
**Rule**: When a crash originates from real data (dirty/NaN/combined values, duplicates,
all-NA groups), fix the root cause — normalize input and guard the reduction — and ALWAYS
add a regression test using the exact problematic input class (e.g. combined position codes,
an all-NaN-`value` player, traded-player `TOT` duplicates). Do not patch only the one record.

### Eliminate NaN at the source, do not mask downstream
**Source**: 2026-06-07-12.40.md, 2026-06-07-13.15.md
**Rule**: Prefer removing NaN where it originates (e.g. `fillna` on the standard error,
dropping NA rows before `idxmax`) over masking it later with `np.where`/conditionals — the
latter still evaluates NaN arithmetic and hides the real gap.
